Home Assistant Bits & Bobs

A collection of reusable Home Assistant blueprints, helpers, automations, templates, scripts, and other useful bits and bobs for building smarter and more practical Home Assistant installations.

The goal of this repository is simple:

Build it once, make it reusable, and share it.

Most of the components here are designed to be generic and configurable rather than tied to a specific installation.
